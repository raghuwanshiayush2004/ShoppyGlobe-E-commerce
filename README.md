# ShoppyGlobe - E-commerce React Application

A fully-featured e-commerce web application built with React, Vite, and Redux for state management.

## GitHub Link: https://github.com/raghuwanshiayush2004/ShoppyGlobe-E-commerce

## 🚀 Features

- **Product Catalog** - Browse and search products
- **Shopping Cart** - Add, remove, and manage items
- **Product Details** - Detailed product views
- **Responsive Design** - Mobile-friendly interface
- **Redux State Management** - Centralized cart and product state
- **React Router** - Navigation between pages
- **Search Functionality** - Filter products in real-time
- **Checkout Process** - Complete order placement flow
- **Error Handling** - 404 page and API error management

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **State Management**: Redux, Redux Thunk
- **Routing**: React Router DOM
- **Styling**: CSS3 with responsive design
- **API**: DummyJSON Products API
- **Performance**: React.lazy, Suspense, Code Splitting

## 📋 Prerequisites

Make sure you have the following installed:
- Node.js 
- npm or yarn package manager

## ⚡ Quick Start

Follow these steps to run the application locally:

### 1. Clone and Install
```bash
# Clone the repository
git clone <your-repo-url>
cd shoppyglobe
```
### 2. Install dependencies
npm install

### 3. Run Development Server
npm run dev
